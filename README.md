# AI Smart Education System

## Project Overview
This project predicts student GPA using Machine Learning based on lifestyle factors such as study hours, sleep hours, stress level, and physical activity.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit

## Features
- Data Cleaning
- Outlier Removal
- Data Visualization
- Linear Regression Model
- GPA Prediction
- Interactive Streamlit Dashboard

## Workflow
Dataset
→ Data Cleaning
→ EDA
→ Feature Engineering
→ Model Training
→ Prediction
→ Streamlit Dashboard

## Machine Learning Model
Linear Regression was used to predict GPA.
