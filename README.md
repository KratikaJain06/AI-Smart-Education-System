Project Title:
AI Smart Education System

Project Description:
This project predicts student GPA based on lifestyle factors such as study hours, sleep hours, stress level, and physical activities

Features:
• Data Cleaning
• Outlier Removal
• Data Visualization
• Linear Regression Model
• GPA Prediction
• Streamlit Dashboard
• Interactive User Inputs
Technologies Used
Area	Tools
Language	Python
Data Science	Pandas, NumPy
Visualization	Matplotlib, Seaborn
ML	Scikit-learn
Dashboard	Streamlit

Workflow:

Dataset
→ Data Cleaning
→ EDA
→ Feature Engineering
→ Train-Test Split
→ Linear Regression
→ Prediction
→ Streamlit Dashboard
ML Model Used
Linear Regression

Linear Regression was used because GPA is continuous numerical data.

Project Workflow:
1. Load dataset
2. Clean missing/duplicate values
3. Remove outliers
4. Visualize data
5. Encode categorical variables
6. Select features
7. Split train and test data
8. Train Linear Regression model
9. Predict GPA
10. Create Streamlit dashboard
11. Display predictions interactively

Features:
Study Hours
Tracks how study time affects GPA.
Sleep Hours
Analyzes relationship between sleep and academic performance.
Stress Level
Measures impact of stress on GPA prediction.
Physical Activity
Studies effect of exercise on student performance.
GPA Prediction
Machine Learning model predicts GPA based on student lifestyle.
Dashboard
Interactive Streamlit dashboard allows users to enter values and receive GPA predictions in real time.
